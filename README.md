# Otido Service

Full-stack website for an auto repair service.

## 🌐 Live Demo

https://otido-service.onrender.com

## 📋 About the project

A responsive website for an auto repair service with a server-side system for processing customer requests.

The project includes a frontend interface, backend API, form validation and Telegram notifications for new customer requests.

## ✨ Features

- Responsive design
- Service information and pricing
- Customer request form
- Server-side form processing
- Input validation
- Telegram notifications
- Anti-spam honeypot
- Rate limiting
- REST API

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Axios
- Telegram Bot API
- Git / GitHub

## 🚀 Run locally

Clone the repository:

```bash
git clone https://github.com/Deniyache/otido-service.git
cd otido-service

npm install
BOT_TOKEN=your_telegram_bot_token
CHAT_ID=your_telegram_chat_id
npm start
http://localhost:3000
